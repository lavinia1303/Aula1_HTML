tag header:

A tag header no HTML serve para criar o cabeçalho de uma página ou de uma seção.

tag main:

A tag main no HTML define o conteúdo principal e único de uma página.

Tag nav:

Cria uma seção de navegação no site.

tag section:

A tag section serve para agrupar conteúdos temáticos relacionados que compartilham um mesmo assunto em um documento HTML.

tag article:

A tag article é utilizada para representar um conteúdo independente e autocontido que pode ser distribuído ou reutilizado separadamente do restante da página

Tag: aside

A tag "Aside" em um código HTML serve para colocar condeúdos secundários, como links, menus laterais, dicas e publicidades.

Tag figure:

Serve para agrupar um conteúdo visual ou autossuficiente (como foto, diagrama, gráfico, etc).

tag footer:

A tag footer define o rodapé de uma página ou de uma seção.
